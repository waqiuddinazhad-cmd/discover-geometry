# Discover Geometry

An interactive single-page explainer and prototype for a geometry sandbox where students **construct, notice, manipulate, then name** angle relationships.

## What it demonstrates

- Drawing two lines that become clean, infinite line vectors.
- Aligning the second line using a visible handle that snaps it parallel—without hiding either line's identity.
- A guardrail that keeps the transversal at a useful slant.
- An acute angle wedge that can be moved, rotated, and resized to discover corresponding angles.
- Plain-language feedback and progressive vocabulary, rather than a rote quiz flow.

## Run it locally

This is dependency-free. Open `index.html` in a modern browser, or serve the folder with any static-file server.

## Publish with GitHub Pages

1. Create a GitHub repository named `discover-geometry` and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Set **Build and deployment** to **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.
5. GitHub will provide the public website URL in the Pages settings.

No build step is required.
